Default right-click menu

Modifier key

Hold the modifier to reach whichever menu isn't the default. Shift + right-click always shows the normal menu, and there's an "Open Radial Tab Menu" fallback item inside it plus a toolbar button.

Always use the normal menu on…

On these, plain right-click always gives Firefox's normal menu — it has items the ring can't reproduce, like Copy Link, Save Image As, spellcheck suggestions and Paste. The radial menu is still available there by holding the modifier.

Orbit buttons

The action buttons around the outside of the ring. Pick what sits at each compass position, or leave one empty.

Firefox doesn't let add-ons read the normal context menu, so these can't be pulled from it — Radiator performs each action itself. Middle-clicking New Tab opens it in the background. Zoom, Pin and Mute keep the ring open so you can hit them repeatedly.

Ring

1.00×

With more tabs than max items, the ring becomes an endless wrap-around window — tabs slide in and out at the bottom as you scroll, and every tab stays reachable.

Theme

Custom CSS

Applied on top of the selected theme. Style hooks: .loz (tab pill), .loz .title, .fav, .badge, .loz.active (current tab), .loz.hi (highlighted), .ctrl (outer buttons), .preview, .label, .notch (selector).
